# Security Policy

## Supported Versions

Only the latest release is supported. Fixes are published as a new release
rather than backported.

## Reporting a Vulnerability

Please **do not open a public issue** for security problems.

Report privately through
[GitHub Security Advisories](https://github.com/patbaumgartner/photo-gallery-wizard/security/advisories/new),
or by email to <contact@patbaumgartner.com>.

Please include what an attacker can achieve, how to reproduce it, and the
version you tested. You should get an acknowledgement within a week.

## Scope

This is a local terminal application, so the interesting surface is narrow:

- Gallery codes and passwords generated by `CodeGeneratorService`
- Credentials sent to `app.schulfotos.base-url` and `app.picpeak.api-url`
- Directory names built from CSV data
- Handling of images and PDFs read from disk or downloaded

## Handling Credentials

PicPeak credentials live in `configuration/picpeak-credentials.properties`,
which is deliberately excluded from version control. Never commit it, and never
paste it into an issue. The generated CSV contains gallery passwords and share
links — treat it as confidential and strip it before attaching it to a report.
